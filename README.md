### Project Description

Anti-Google is an intentionally useless AI-powered website that does the opposite of a normal search engine. Instead of providing answers to users' questions, it responds with funny, creative, and question-specific counter-questions.

The project turns a normally useful search experience into a deliberately useless and entertaining interaction using web technologies and LLM-based response generation.

### The Problem (that doesn't exist)

People already have Google, search engines, and AI assistants to answer almost every question they can think of.

So we identified a completely unnecessary problem:

**"What if people are getting answers too easily?"**

Our project solves this non-existent problem by creating a website that refuses to give the answer.

Because apparently, the internet needed one more website that doesn't help. 😂

### The Solution (that nobody asked for)

Anti-Google takes the user's question and deliberately avoids giving the expected answer.

Instead, the system understands the question and generates a funny, creative, and relevant counter-question or mocking response.

For example:

**User:**
> What is 2 + 2?

**Anti-Google:**
> Why do you need me for this? Please look at your fingers and try again.

The user can then ask another question, and Anti-Google repeats the same process with a new response based on that particular question.

## Implementation

### For Software:

# Installation

1. Clone the repository from GitHub.

git clone <YOUR-GITHUB-REPOSITORY-URL>

2. Open the project directory.

cd Anti-Google

3. Install the required dependencies.

npm install

4. Make sure Node.js and npm are installed on your computer.


# Run

Start the development server.

npm run dev

After the server starts, open the local URL shown in the terminal in your web browser.

The Anti-Google website will then be ready to use.
